# 检索与筛选规则

## 范围、窗口与基线

固定八家：华为、平头哥、海光、昆仑芯、摩尔线程、燧原科技、寒武纪、壁仞科技。仅收录与AI算力产品或产品线有关的技术、产品阶段、软件、价格、客户及销售信息。公司总收入和泛合作消息不能直接推为AI芯片收入或落地。

首次取截止日期及此前29个自然日。读取用户指定或工作区直接可见的已有报告／台账作为参考，不遍历其他目录找基线。增量依据最近报告各厂商的有效完成日期向前回看7天；中断期间不跳过，部分或聚焦扫描不推进全主题完成日期。没有可靠历史时注明新增性待判断。

先读最近报告，再用厂商、型号、事件或编号定向找相关历史。此前报告未出现某事件不等于它首次发生；新报道讨论旧事件时分别说明。

## 查询与信源

| 方向 | 做法 |
| --- | --- |
| 产品技术与阶段 | 厂商／型号＋新品、规格、软件、展示、路线图、量产等，优先官方入口 |
| 价格与商业 | 厂商／产品线＋价格、采购、中标、客户、订单、部署、交付、收入等，排除同名企业与CPU等无关噪声 |
| 活动与行业媒体 | 根据本轮活动或具体线索补查演讲、展台、原创报道、具名现场记录和独立测试；不逐厂商机械凑查询 |

使用公开中英文材料。优先产品文档、新闻稿、投资者披露、公开招采、会议主办方、演讲及现场记录，再补原创采访、行业媒体和独立测试。非官方早期线索可保留，不以官网确认作为发现前提。

不主动检索或访问微信公众号文章，不做公众号域名定向、不追作者公众号、不为其留补查额度。同作者在其他公开网站的版本正常引用实际承载页面；用户提供的可读正文注明为提供材料。普通报告无需声明公众号覆盖缺口。

查询使用短表达式，先核实域名再做站内限定，检查运算符写法，不猜测站点。活动日期以本轮实际材料为准，不按记忆假设近期举办。发现明确别名或新型号时再补查，避免多词堆叠和重复换词。

## 初查与判断

初查关键来源的产品指向、事件与发布日期、主要说法及必要定位，不补齐完整规格。用短句区分官方原文、具名现场记录、二手报道与摘要线索，以及正文已读、部分可见或无法取得。多来源分别说明，不能共用一个已读标记。

厂商性能说法写为厂商宣称；记者观察与独立测试分别表述。保留精度、配置、模型和测试条件中的已知部分。预算、报价、成交价分开；意向、订单、交付、部署、验收、收入分开；路线图使用未来时态。未知不补造，不按不同口径排名。

报道日期、事件日期和更新日期分别处理。搜索抓取日期不当发布日期；日期未知留空或说明。读取图表和附件后才引用其中数值。

| 初筛建议 | 条件 |
| --- | --- |
| 建议深挖 | 新型号、关键能力／阶段变化、具体价格或商业事件可能改变判断，且有可追踪入口 |
| 保留观察 | 可能重要，但指向、证据或新增性不足，或本轮尚未完成初查 |
| 本轮无需深挖 | 重复、无实质补充或关联较弱；仅列容易误判的代表项及理由 |

重要性与证据可靠程度分别判断。重复官方新闻未必值得深挖，尚待核实的重要线索也可推荐。所有已发现且有出处的重要新型号、关键变化都须保留，不硬设推荐条数上限。

按“厂商＋产品／产品线＋事件／主张＋阶段”去重。同稿转载合并为一条，优先最接近原始发布的版本；有实质补充时沿用编号，在新报告说明变化并链接旧报告。独立新阶段、价格事件或客户落地可新建关联候选。

## 成本与覆盖

先完成技术、商业基础方向，活动／媒体按线索开展；通常不超过24次基础查询，最多再补8次，不同原文页面初查默认最多24个。聚焦子集时相应减少，不为用满额度搜索。

同稿不重复打开，已取到相关原文先整理所需段落；同一运行的可核原文片段可供第二阶段复用。仅有摘要的记录不能作为已读原文。用量和来源访问状态在执行中内部计数；普通成果不列过程清单，询问成本时可汇总，明确测试诊断时才展开。

明确403、404、付费或访问控制后转向其他公开来源；普通超时最多合理重试一次，不绕过工具或站点限制。达到初筛额度后保留重要未查线索和范围缺口。无新线索时停止换词，不承诺全网无遗漏。
