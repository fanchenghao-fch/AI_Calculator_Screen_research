# AI 芯片竞对调研 Skill 组合

面向 AI 芯片市场观察的两阶段研究工具：先发现竞对线索，再对人工选中的候选开展深挖，并将研究报告收录至离线看板。

固定关注华为、平头哥、海光、昆仑芯、摩尔线程、燧原科技、寒武纪、壁仞科技。

## 目录

- [初筛技能](AI芯片竞对调研Skill组合/ai-chip-signal-screening/SKILL.md)：扫描、去重并提出候选，交由用户选择。
- [深挖技能](AI芯片竞对调研Skill组合/ai-chip-signal-research/SKILL.md)：研究用户明确选中的候选，保存报告、回链并更新看板。
- [研究成果](AI芯片竞对调研Skill组合/成果/)：保留初筛、深挖报告及历史批次。
- [离线看板](AI芯片竞对调研Skill组合/看板/竞对看板.html)：下载仓库后用浏览器打开。
- [看板使用与维护](AI芯片竞对调研Skill组合/看板/使用与维护.md)：补录、重建与异常恢复说明。

## 使用

下载或克隆整个仓库，并保留目录结构。将本仓库作为工作区，在支持 Skill 的助手中加载对应的 `SKILL.md` 及其引用文件。技能能否自动发现，取决于所用助手的安装配置。

初筛示例：“请按 ai-chip-signal-screening 扫描最近 30 天的竞对线索。”

深挖示例：“请按 ai-chip-signal-research，研究指定筛选报告中的指定候选编号。”

初筛不会自动触发深挖；深挖需用户明确选择。正常研究结果保存至组合目录的 `成果/初筛/` 或 `成果/深挖/`。报告中的事实与核查日期以原报告为准，历史成果不代表当前事实已重新核验。

## 看板维护

看板可离线阅读，外部来源链接需要联网。重新构建需要本地 Node.js，无需安装第三方依赖：

```sh
cd AI芯片竞对调研Skill组合/看板
node scripts/build-dashboard.cjs --rebuild
```

维护程序的回归检查：

```sh
node --test tests/maintenance.test.cjs
```

第三方 Markdown 解析器及其许可保留在 `看板/vendor/` 中。
